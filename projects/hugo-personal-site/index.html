Original Hugo Personal Site

The first generation of this portfolio, built with Hugo and maintained from 2022 through 2026.

  • Static Site
View archived source

This Hugo site was my first substantial static-site project. I customized templates and SCSS, modeled projects and resume content as YAML, and used a Git submodule workflow to publish generated files through GitHub Pages.

In 2026 I replaced it with the current Astro site to simplify the design, make projects the primary focus, and remove the dependency on an external theme.
