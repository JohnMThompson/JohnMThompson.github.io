Zoomix

A Linux Mint screen zoom, annotation, and image snip utility inspired by Microsoft Sysinternals ZoomIt.

  • Rust
  • Linux
  • Desktop App
GitHub repository

Zoomix brings presentation-friendly screen tools to Linux Mint Cinnamon on X11. Global hotkeys open a frozen or live magnified view centered on the cursor, start a full-screen drawing surface, or capture a selected region as a PNG and copy it to the clipboard.

The annotation overlay includes freehand drawing, rectangles, arrows, lines, ellipses, highlights, text, an eraser, undo, and configurable colors. Hotkeys can be customized in a TOML configuration file, while focused logging helps diagnose startup, mode, and capture issues without recording noisy per-frame events.

The application is written in Rust and integrates directly with GTK, X11, Cairo, and Pango. It includes Debian packaging, a Linux Mint application launcher, an optional autostart configuration, automated formatting and lint checks, and unit tests.
