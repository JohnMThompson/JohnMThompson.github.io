Tableau Complexity

A Python utility that inspects Tableau workbooks and calculates a configurable complexity score.

  • Python
  • CLI
  • Tableau
GitHub repository View on Tiny Tool Town

Tableau Complexity parses .twb and .twbx workbooks to extract worksheet-level metadata such as marks, shelves, filters, calculations, and parameters. It combines those signals into a configurable complexity score.

The utility is intended to make workbook assessment more consistent during governance, migration, and cleanup efforts. It can be run from the command line or used through a browser-based interface on Tiny Tool Town.
