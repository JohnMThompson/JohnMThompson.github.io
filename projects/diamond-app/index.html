Diamond App

A Flask application that estimated the cost of a three-stone engagement ring from local jeweler data.

  • Python
  • Web App
  • Data Analysis
GitHub repository

I gathered pricing data from local jewelers and built a small Flask application to estimate the cost of a three-stone engagement ring.

The application was originally deployed on Heroku and was retired when its free hosting tier ended. The source remains available as an early example of turning a personal question into a focused data product.
