Mortgage Rate App

A daily mortgage-rate collection pipeline and dashboard built to understand market movement while buying a home.

  • Python
  • Automation
  • Data Visualization
Open dashboard GitHub repository Read the build article

I created this application while house hunting to replace the daily routine of checking lender websites and mentally tracking whether rates were moving up or down.

A scheduled Python process retrieves and parses published rates, stores the observations, and makes the history available through the Analytics Hub. The project covers the complete data path from collection and scheduling through storage, API delivery, and visualization.

The original dashboard used Metabase. I migrated it into the Analytics Hub in 2026 while preserving the historical dataset.
