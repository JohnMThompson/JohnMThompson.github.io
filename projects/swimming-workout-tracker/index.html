Swimming Workout Tracker

A personal training log for exploring workout trends, stroke mix, pace, distance, and long-term swimming progress.

  • Python
  • Web App
  • Data Visualization
Open dashboard Read the original tutorial

I started tracking lap swimming in 2023 and used the project to explore how an analytics interface could also support data entry and maintenance.

The first version used Metabase Actions to create, update, and delete workouts from a dashboard. In 2026 I migrated the experience into the Analytics Hub, where it now provides purpose-built views of volume, pace, strokes, records, and individual workouts.
