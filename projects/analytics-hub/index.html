Analytics and Reporting Hub

A self-hosted home for practical dashboards and personal data products, backed by a Python API and a modern responsive frontend.

  • Python
  • Web App
  • Data Visualization
Open Analytics Hub GitHub repository

I built the Analytics and Reporting Hub to consolidate personal dashboards that had outgrown their original Metabase deployment. It gives each project a focused interface while sharing one deployment, API, database connection layer, and visual system.

The hub currently includes mortgage rate tracking, swimming history, a concert calendar, Halloween tracking, and home-office environmental data. It is also the visual reference for this portfolio: clear typography, quiet surfaces, useful color, and responsive card-based navigation.

The project is an ongoing exercise in product design, application architecture, API development, testing, deployment, and operating software that I use in everyday life.
