Finn-structions

A small documentation site with everything a caregiver needs to know while looking after Finn.

  • Python
  • Static Site
Visit Finn-structions GitHub repository

I wanted to learn MkDocs through a real project rather than a generic demonstration. Care instructions for Finn gave the site a useful audience and clear information architecture.

The result is a lightweight reference covering routines, food, walks, behavior, and other details that are easy to forget when handing care to someone else.
