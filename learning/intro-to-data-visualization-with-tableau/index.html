Intro to Data Visualization with Tableau

Learn the fundamentals of effective data visualization while building your first Tableau dashboards using real data.

  • Tableau
  • Beginner

Presented at Twin Cities Data Science & Analytics · Bloomington, MN

Overview

Session Overview

Audience
Beginning Tableau users and anyone interested in learning the fundamentals of data visualization.
Duration
90 minutes
Software
Tableau Public (Web)
Prerequisites
None

This session is designed for anyone who wants to build a solid foundation in data visualization using Tableau. Rather than focusing on software features alone, it emphasizes the principles behind effective visual communication: choosing the right chart, reducing unnecessary complexity, and designing dashboards that help people understand data more quickly.

During the workshop, participants build several common chart types from a simple weather dataset before combining them into an interactive dashboard. Along the way, we explore practical Tableau techniques, discuss common visualization mistakes, and develop habits that translate well beyond Tableau to other analytics tools.

The downloadable resources include the presentation slides and the sample dataset used during the session, making it easy to revisit the material or follow along at your own pace. A recording of the session will be added once it becomes available.
